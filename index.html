Install Aplikasi

Jika tombol install bawaan browser belum muncul, gunakan menu browser untuk memasang aplikasi ke layar utama.

  • Chrome Android: buka menu titik tiga, lalu pilih Install app atau Tambahkan ke layar utama.
  • Safari iPhone: tekan tombol Share, lalu pilih Add to Home Screen.
  • Desktop: buka alamat aplikasi melalui HTTPS, lalu gunakan ikon install di address bar bila tersedia.
